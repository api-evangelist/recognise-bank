# Recognise Bank

> Recognise Bank Limited is a UK challenger bank for the SME sector and personal/business savings markets, offering fixed-rate, notice and easy-access savings accounts alongside secured SME lending (bridging loans, commercial mortgages). PRA-authorised and FCA-regulated (FRN 849404), FSCS-protected. It does not offer payment/current accounts, is not one of the CMA9, and publishes no dedicated developer portal or confirmed Open Banking API at review time. The UK Open Banking (OBIE / PSD2) specifications are included here as the shared industry standard the bank would conform to if it exposed regulated interfaces — not as confirmed Recognise-operated endpoints.

## APIs (OBIE standard specs — shared standard, not confirmed Recognise endpoints)
- [UK Open Banking Open Data API (OBIE Standard)](https://github.com/OpenBankingUK/opendata-api-spec-compiled): Public reference data (ATMs, branches, accounts, products).
- [UK Open Banking Account & Transaction Information API (OBIE Standard)](https://github.com/OpenBankingUK/read-write-api-specs): FAPI-secured AIS Read/Write standard.
- [UK Open Banking Payment Initiation API (OBIE Standard)](https://github.com/OpenBankingUK/read-write-api-specs): FAPI-secured PIS Read/Write standard.
- [UK Open Banking Confirmation of Funds API (OBIE Standard)](https://github.com/OpenBankingUK/read-write-api-specs): FAPI-secured CBPII Read/Write standard.
